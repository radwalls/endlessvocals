Help & support

Open mapper

Find lyrics and start a map

Choose Find lyrics, search by artist and song title, select a match, and review the text before adding it. You can also paste lyrics you have permission to use. An empty map takes the found song’s name and lyrics; an existing map with lyrics stays intact while a new map is created.

Shape lyrics without losing your place

Tap a word or line to bring its controls around the selected lyric. Tap or drag across line numbers to select several lines. Use Sections to mark an intro, verse, chorus, bridge, or outro, then tap a section name to jump back to it.

Map syllables on the piano roll

Choose a lyric line and word on the Piano Roll, then assign each syllable a note. Edit split lets you adjust where a word separates. Hold + pitch adds another note to the same syllable when the melody moves while you sustain it.

Save, move, and remove maps

Maps save on the current device or in the current browser. Open Map options → Saved maps to switch maps or use Manage to delete one with confirmation. Export a .smap file to back up or move a map between the website and iPhone app; import that file on the other device.
