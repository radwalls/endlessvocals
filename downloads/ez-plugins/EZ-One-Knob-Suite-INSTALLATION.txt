RAD WALLS x ENDLESS VOCALS — EZ ONE-KNOB SUITE 0.3.0

Thank you for supporting independent music tools and vocal education.

INCLUDED
EZ Verb, EZ Delay, EZ Doubler, EZ Chorus, EZ Pressor, EZ D-esser,
EZ Q, EZ Sat, EZ Tone, and EZ Tuner.

FORMATS
- Components: Audio Unit format for Logic Pro and other AU hosts on macOS.
- VST3: VST3 format for Ableton Live, Cubase, Reaper, Studio One, and other
  VST3 hosts on macOS.

LOGIC PRO / AUDIO UNIT INSTALLATION
1. Quit Logic Pro.
2. Copy all ten .component files from Components to:
   ~/Library/Audio/Plug-Ins/Components/
3. Reopen Logic Pro.
4. If needed, use Logic Pro > Settings > Plug-in Manager and rescan them.

VST3 INSTALLATION
1. Quit your DAW.
2. Copy all ten .vst3 files from VST3 to:
   ~/Library/Audio/Plug-Ins/VST3/
3. Reopen your DAW and rescan plug-ins if needed.

CHANNEL CHOICES
Every plug-in supports mono, mono-to-stereo, and stereo in the same download.
Your DAW chooses the matching layout when you insert it.

Apple Silicon Mac with macOS 13 or newer.
