LOGIC PRO / AUDIO UNIT INSTALLATION
1. Open the Components folder in this download.
2. Copy all nine .component files to:
   Macintosh HD/Library/Audio/Plug-Ins/Components
3. Restart Logic Pro.
4. Find the plug-ins under Audio FX > Rad Walls.

If Logic was open during installation, quit and reopen it. If a plug-in still
does not appear, open Logic Pro > Settings > Plug-in Manager and rescan it.
